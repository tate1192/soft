# Soft Web Map — Contacts

Adds the `leaflet_map` view to the Contacts application.

This bridge module depends on `soft_web_map`, `contacts` and
`base_geolocalize`. Install it if you want the map view in the Contacts
action; the core `soft_web_map` module can be used on any model without
installing Contacts.

See `soft_web_map/README.md` for configuration and view architecture.
