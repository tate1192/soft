Soft Web Map

A Leaflet / OpenStreetMap view for Odoo 19. Display any model with latitude and longitude fields as an interactive map, with a record sidebar, marker popups and optional clustering.

The core module is standalone. Install the optional Soft Web Map — Contacts bridge to add the map view to the Contacts application.

Features

  • Leaflet 1.9 map with OpenStreetMap tiles
  • Marker popups with name, address, email and phone
  • Record sidebar with search, pager and Google Maps directions
  • Optional marker clustering
  • Responsive desktop and mobile layout
  • Configurable tile URL and attribution
  • Turkish and English user interface

Configuration

Set soft_web_map.tile_url and soft_web_map.copyright in Settings → Technical → Parameters → System Parameters. 

<leaflet_map latitude="partner_latitude"
             longitude="partner_longitude"
             limit="80"
             clustering="1">
    <field name="display_name"/>
</leaflet_map>
