Soft Gantt

A native Gantt / timeline view type for Odoo 19 Community and Enterprise. No Enterprise code copied, no vendored JavaScript library: the bars, the drag and drop, the milestones and the dependency arrows are drawn by the view itself.

Odoo 19 Community ships no gantt view: that type only exists in the Enterprise add-on web_gantt. This module adds a view type of its own, gantt_soft, registered the same way the core registers its extra view types. The two types live side by side, so the same module runs on a Community and on an Enterprise database: a screen lists the one it wants.

Features

  • Rows from the records, dates named by the view itself: the same type schedules any model with two date fields
  • A window, not a table: one calendar unit is read at a time, so a table of years of history stays fast
  • Day / week / month / quarter / year scales, with a two level header, today marked and optional cell precision (quarter hours of a day, half days of a week or a month)
  • Drag a bar to reschedule it, drag an edge to change one date
  • Milestones drawn as a diamond on their date
  • Dependency arrows between the records a relational field names
  • One row per record, or one row per group (group_by), or a tree of groups (group_by="team_id,type_id"); lanes for overlapping records, foldable groups, per-level counts and totals
  • Progress bar, colour index, decoration expressions and a details card per record, with the record actions the view declares (<button>: a method call or an action, optionally confirmed)
  • Group rows that count their records, sum a numeric field (group_total), show an avatar (group_avatar) and can start folded (collapse_first_level)
  • Create from the grid (cell_create): a double click on an empty cell opens the form with the dates defaulted, the "+" of a group row with the group defaulted
  • Fit the whole search in one click, and export the period as CSV
  • Search filters and favourites really reload the view
  • Light and dark colour scheme, driven by SCSS variables
  • English and Turkish user interface

Usage

A Gantt view is declared like any other view:

<record id="my_model_gantt_view" model="ir.ui.view">
    <field name="model">my.model</field>
    <field name="arch" type="xml">
        <gantt_soft date_start="date_start"
                    date_stop="date_end"
                    label="name"
                    progress="progress"
                    milestone="is_milestone"
                    dependencies="depends_on"
                    group_by="team_id"
                    scales="day,week,month,quarter,year"
                    mode="week"/>
    </field>
</record>

The mode is then offered to the view switcher by adding gantt_soft to the action's view_mode, from a consumer module that names the model.

Validation

Every attribute that can be checked without a browser is checked when the view is installed: an unknown field, a Char field used as a date, an unknown attribute, a bad scale, a non-positive limit or a dependency list pointing at another model refuses the view with a message that names the problem, instead of showing an empty schedule.
